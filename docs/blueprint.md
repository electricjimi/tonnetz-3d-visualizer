# **App Name**: Tonnetz Visualizer

## Core Features:

- 3D Tonnetz Generation: Generates a 3D Tonnetz visualization based on user-selected parameters (limit 5 or limit 7 intonation).
- Intonation Limit Selection: Allows users to select between Limit 5 and Limit 7 intonation for the Tonnetz.
- Interactive Controls: Provides interactive controls to rotate, zoom, and pan the 3D Tonnetz for detailed exploration.

## Style Guidelines:

- Primary color: Dark blue (#222831) for the background to make the Tonnetz stand out.
- Secondary color: Light gray (#EEEEEE) for the Tonnetz lines and labels to provide contrast.
- Accent: Teal (#00ADB5) for interactive elements and highlights to draw attention.
- Clean and legible sans-serif font for labels and UI elements.
- Simple and intuitive icons for controls (rotation, zoom, pan, intonation limit).
- Clean and intuitive layout, with the 3D Tonnetz visualization taking center stage and controls positioned around it.
- Smooth transitions and animations for rotations, zooms, and intonation limit changes.

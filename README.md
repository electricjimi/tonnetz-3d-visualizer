# Tonnetz Visualizer

## What is it?

The Tonnetz Visualizer is an interactive web application designed to explore and understand the Tonnetz, a visual representation of musical pitch relationships.

## How does it work?

The Tonnetz (German for "tone-network") is a conceptual map that represents the relationships between musical pitches based on just intonation, specifically, the pure intervals of major and minor thirds and perfect fifths. In this application:

*   **Nodes:** Each node in the network represents a musical pitch (e.g., C, C#, D, etc.).
*   **Edges:** The edges between nodes represent the intervals between those pitches. Different edge colors highlight different intervals.
    * Red: Perfect Fifth
    * Blue: Major and Minor Third
    * Teal: Harmonic seventh (if limit is 7)

## Interactive Exploration

This interface is fully interactive. You can:

*   **Click:** Click on a node to hear the corresponding pitch.
*   **Hover:** Hover over nodes to highlight them.
*   **Drag and Zoom:** Drag to rotate the network and zoom in/out to examine the relationships from different perspectives.
